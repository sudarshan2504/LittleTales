# LittleTales 📖✨
> **Little stories. Big adventures.**
> An interactive storytelling, 2D parallax adventure, and missing-letter spelling platform for kids.

---

## 🌟 Highlights

- **Interactive 2D Parallax Reading**: Multi-layered depth across 6 custom SVG environments (Forest, Savanna, Space, Pond, Fantasy, Ocean).
- **Interactive Characters**: Tap characters and scenes to trigger animated responses, speech bubbles, and sound effects.
- **Web Speech Narration**: Integrated child-friendly voice narration with play, pause, resume, and stop controls.
- **Typed Missing-Letter Quests**: Active spelling activities featuring 2 levels of hints, friendly feedback, and real-time score tracking.
- **My Adventures Reading Passport**: Local tracking of stories started, completed, best scores, and achievement badges.
- **Parent Corner**: Insights into phonics, language acquisition pedagogy, and a 100% child-safe, local-only privacy model.
- **Zero External Tracking**: No cookies, ads, or third-party telemetry. All data is saved strictly to your local device.

## 📚 Storybook Collection

1. **The Lost Bunny** (*Animals • Easy*) — Join Pip on a sunny morning trail to explore the forest and discover the way home.
2. **Leo the Little Lion** (*Adventure • Easy*) — Help Leo cross the wooden rope bridge and learn what true courage means.
3. **Mia Goes to Space** (*Space • Medium*) — Rocket past the clouds with Mia, tour Saturn’s rings, and draw star constellations with Zorb.
4. **The Slow Turtle** (*Animals • Easy*) — Cheer on Timo during the meadow race as kindness and patience win the day.
5. **The Little Dragon** (*Fantasy • Medium*) — Watch Ember discover the magic of glowing starlight sneezes to brighten the dark festival lanterns.
6. **Ocean Adventure** (*Ocean • Advanced*) — Swim with Bubbles the baby whale and sing whale songs across deep sea trenches to reunite a lost dolphin pod.

## 🚀 Tech Stack

- **Frontend**: React 19 + Vite
- **Animations**: CSS Keyframe Animations & Parallax Transforms
- **Icons**: Lucide React
- **Celebrations**: Canvas-Confetti
- **Typography**: Google Fonts (Fredoka & Nunito)
- **Audio**: Web Speech Synthesis API
- **Storage**: LocalStorage with automatic in-memory fallback

## 🛠️ Quick Start

```bash
# 1. Clone the repository
git clone <your-repo-url>
cd story-telling

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build for production
npm run build
```
